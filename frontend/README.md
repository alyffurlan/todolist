# TODOLIST - Frontend (React + Vite)

## Como rodar
1. Suba o backend (pasta `backend`): `npm install` e `npm run dev` (porta 3333). O MySQL precisa estar rodando com o `schema.sql` aplicado.
2. Nesta pasta: `npm install` e `npm run dev`
3. Acesse http://localhost:5173

O Vite faz proxy de `/api` para `http://localhost:3333`.
